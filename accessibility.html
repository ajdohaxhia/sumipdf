Accessibility

Sumi PDF targets WCAG 2.2 AA for the application chrome: home, search, tool pages, and the workflow builder. PDF documents themselves may be inaccessible; the tools cannot invent structure that a file does not have.

  • Visible focus and skip-capable landmarks
  • Keyboard access to search (Control/Command+K)
  • Language and theme controls with accessible names
  • prefers-reduced-motion is honored
  • Status text is announced through an aria-live region

Report interface barriers via GitHub issues on the source repository. Do not attach confidential PDFs.
