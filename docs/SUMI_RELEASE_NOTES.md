# Sumi PDF 1.0 release notes

Sumi PDF is a privacy-first, client-side PDF workspace derived from BentoPDF.

## Promise

Powerful PDF tools. Your files stay on your device.

No account. No artificial limits. No document uploads.

## Highlights

- Command-center home with immediate file drop and tool search
- Shared application shell, light/dark/system theme
- Session-only local workspace for tool handoff
- Workflow recipes plus an accessible list view
- Privacy Clean verification report
- Real redaction via PyMuPDF (not a drawn black box)
- English and Italian product surfaces; other locales fall back

## Honest limits

- Device RAM still applies
- Visual signatures are not cryptographic signatures
- PDF/A conversion is best-effort
- Some engines load version-pinned WASM from a CDN unless self-hosted
- Playwright E2E and Lighthouse scores are not claimed unless recorded in the implementation log
