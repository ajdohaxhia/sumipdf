# Sumi original features — evidence matrix

Audited upstream: [alam00000/bentopdf](https://github.com/alam00000/bentopdf) `main` SHA **`5bf54f1dad75bdf3139e6314671f730f4c4a28de`**.

This file is the honesty check for the Originals Expansion Pass. Branding is not originality. A renamed BentoPDF tool is not a Sumi invention. Originality means **useful behavior that the audited upstream tree does not provide**, even if Sumi reuses upstream engines through adapters.

`origin` on the canonical tool registry (`src/js/config/tool-registry.ts`) is **internal only**. Do not paint origin badges on the homepage or tool cards.

## How to read the matrix

| Column                    | Meaning                                                                       |
| ------------------------- | ----------------------------------------------------------------------------- |
| **BentoPDF status**       | What exists at the audited SHA (name the upstream tool, not a slogan).        |
| **Sumi extension**        | What Sumi adds on top of that engine or page.                                 |
| **Truly new behavior**    | The user-visible job that BentoPDF did not do. Empty if the work is a reskin. |
| **Implementation status** | `done`, `partial`, `not started`, or `experimental`.                          |

## What this pass must not claim

Do not market the following as Sumi inventions: workflow builder, compare, OCR compare, sanitization, metadata removal, manual redaction, OCR, forms, blank-page removal, split by bookmarks, PDF/A, or digital signatures.

Do not claim: malware-free, ISO 19005 PDF/A, PDF/UA, WCAG, legal hold, cryptographic timestamp, or identity of persons from a name/address model.

## Engines (adapters only)

Original modules call upstream through adapters and dynamic import:

| Job                                      | Engine                                                         |
| ---------------------------------------- | -------------------------------------------------------------- |
| Catalog / objects / forms                | pdf-lib                                                        |
| Text layer / preview / perceptual render | PDF.js (after user action)                                     |
| True redaction                           | PyMuPDF `addRedaction` / `applyRedactions`                     |
| Bookmark split                           | existing split helpers + cpdf when present                     |
| ZIP                                      | JSZip, in-memory                                               |
| Spreadsheet rows                         | Papa Parse, SheetJS                                            |
| Hashes                                   | Web Crypto SHA-256                                             |
| OCR fallback                             | Tesseract, only when the text layer is empty and the user asks |
| Camera                                   | `getUserMedia` after click; File input fallback                |
| Watch Folder                             | `showDirectoryPicker` when the browser allows it               |

Homepage (`src/js/main.ts`) must not static-import PDF.js, PyMuPDF, LibreOffice, OCR, OpenCV, barcode decoders, or qpdf.
